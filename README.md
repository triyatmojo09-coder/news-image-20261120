One image that sums up the world's news of Friday, 20 November 2026, drawn as a
broadsheet front page: the Shenzhen three-way summit and its peace declaration,
the World Court's genocide ruling against Myanmar, the AI sell-off in global
markets, the missile that damaged a Riyadh tower, and Kenya's last Ebola patient
going home — with a ticker of the day's other stories along the bottom.

The repository holds the finished image as `entry.png`; `main.py` copies it to
`/output/entry.png` byte for byte, so every run produces the identical image.

## Run it
